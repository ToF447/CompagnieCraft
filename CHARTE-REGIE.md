# Régie contemporaine

Direction remplacée à la demande de l’utilisateur par l’habillage Compagnie dans `dist/compagnie.css`. Ce document conserve la description de la version précédente.

Une identité originale pour les coulisses du spectacle vivant : papier d’affiche, scène abstraite et outils de travail sobres.

| Usage | Couleur |
| --- | --- |
| Navigation et encre profonde | `#242321` |
| Fond de travail ivoire | `#F5F2EB` |
| Papier des fiches | `#FFFDF8` |
| Action principale vermillon | `#B83F32` |
| Laiton décoratif | `#E2BB74` |
| Texte courant | `#292723` |

Anton pour les titres d’affiche et les grands chiffres ; Georgia italique pour les accroches ; Source Sans 3 pour les commandes et le contenu. Polices locales, licences dans dist/fonts.

Le décor de scène est dessiné en CSS. Les étapes gardent leurs libellés textuels : les couleurs ne portent pas seules l’information. Focus clavier visible, mouvement réduit respecté, navigation défilante sur mobile, calendrier accompagné d’une liste.

La charte concerne le prototype En compagnie. Le site public et l’administration actuelle Du Sol Au Plafond ne sont pas modifiés.
